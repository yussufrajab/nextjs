## 1. Introduction

### 1.1 Purpose

This User Acceptance Test (UAT) document verifies that the Civil Service Management System (CSMS) meets all business requirements for managing civil service employees in Zanzibar. The system provides comprehensive HR lifecycle management from hiring through separation, including multi-stage approval workflows, document management, and reporting capabilities.

### 1.2 Scope

The UAT covers the following CSMS functionalities:

**Request Management Modules (two-stage workflow: HRO → HRRP → Commission):**

- Confirmation Requests (Probation completion)
- Promotion Requests (Experience-based & Education-based)
- Leave Without Pay (LWOP) Requests
- Cadre Change Requests
- Retirement Requests (Voluntary, Compulsory, Illness)
- Resignation Requests
- Service Extension Requests
- Termination/Dismissal Requests

**Other Modules:**

- Complaint Management (Employee grievances, AI-assisted rewriting, confidentiality)
- Employee Profile Management
- Request Status Tracking
- Recent Activities & Audit Trail
- Reports and Analytics (9 report types, bilingual Swahili/English)
- HRIMS Integration (External data sync)
- User & Institution Management
- Dashboard & Notifications
- Security (MFA, password policy, account lockout, IP banning, session timeout)

### 1.3 Test Objectives

- Verify all 10 user roles function with correct permissions (incl. Pemba-scoped variants)
- Validate all request type workflows (HRO submits → HRRP reviews → Commission decides)
- Test role-based access control (CSC vs Institution-based vs Pemba-scoped)
- Confirm data isolation between institutions and islands (Unguja/Pemba)
- Test file upload/download (MinIO storage, PDF only, **1 MB max**)
- Validate notification system (English & Swahili, in-app + email)
- Ensure employee status restrictions work correctly
- Test reporting system (9 report types, bilingual, PDF/Excel export)
- Verify HRIMS integration functionality
- Confirm approval workflows and status tracking with FSM validation
- Verify MFA for Admin, CSCS, and HHRMD roles
- Verify password complexity (12+ chars, 4 classes) and expiration (90 days / 60 days Admin)
- Verify account lockout (5 failed attempts) and IP banning (10 failed logins)
- Verify session inactivity timeout (10 minutes)

### **Module:** Employee Confirmation Requests

### **Test Case No.: 2**

**Process/Function Name:** Employee Confirmation Request Submission and Approval

**Function Description:** This module handles confirmation of employees who have completed their probationary period. HRO submits confirmation requests to HRRP, who reviews and forwards to the Commission (HHRMD/HRMO). HRRP may also submit directly (auto-approving the HRRP stage). Upon Commission approval, employee status changes from "On Probation" to "Confirmed" and confirmation date is recorded. A commission letter is required for final Commission decisions. Status transitions are enforced by a finite-state machine (FSM) that prevents skipping stages or re-approving concluded requests. Self-approval is blocked.
